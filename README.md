# KERJAREADY Beta

Asisten karier berbasis AI untuk membantu kamu menyiapkan CV dan mencocokkannya dengan lowongan yang kamu incar.

Repositori ini hanya berisi file APK untuk beta tertutup (Android). Kode aplikasi tidak dipublikasikan di sini.

## Unduh

**[Unduh kerjaready-beta.apk (versi terbaru)](https://github.com/sabarmann17/kerjaready-beta/releases/latest/download/kerjaready-beta.apk)**

Panduan lengkap: https://kerjaready.kerjain.work

## Cara pasang

1. Buka tautan unduh di atas dari HP Android.
2. Setelah selesai, ketuk file `kerjaready-beta.apk`.
3. Kalau muncul peringatan "sumber tidak dikenal", izinkan pemasangan dari browser/File Manager untuk sementara.
4. Kalau Play Protect bertanya, pilih **Detail lainnya → Tetap instal**. Ini wajar untuk aplikasi yang belum ada di Play Store.
5. Pernah pasang versi beta lama yang dikirim lewat file? Hapus dulu, lalu pasang versi ini (kunci tanda tangannya sudah diganti ke kunci rilis).

## Cek keaslian file

Setiap rilis mencantumkan SHA-256 file APK. Pastikan nilainya sama dengan file yang kamu unduh.
