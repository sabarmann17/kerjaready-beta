Kebijakan Privasi Potensiku

Terakhir diperbarui: 27 November 2026

Potensiku ("kami") adalah aplikasi pendamping persiapan karier. Kebijakan ini menjelaskan data apa yang kami proses, untuk apa, dan hak-hakmu sesuai Undang-Undang Nomor 27 Tahun 2022 tentang Pelindungan Data Pribadi (UU PDP).

1. Data yang kami proses

  • Akun: alamat email (untuk masuk dengan kode OTP di aplikasi Android), atau nama dan alamat email dari akun Google bila kamu masuk dengan Google (versi web). Kami tidak menerima kata sandi Google, isi Gmail, atau file Drive-mu.
  • Isi CV yang kamu tulis: nama, kontak, kota, pendidikan, pengalaman, proyek, keahlian, sertifikasi, tautan LinkedIn/portofolio, foto (opsional).
  • Pengaturan CV: judul, tipe, template, urutan bagian, riwayat versi.
  • Pemakaian AI: jumlah kredit terpakai, jenis fitur, dan jumlah token (tanpa isi CV) untuk menghitung biaya.
  • Hak akses trial/beta: hash satu arah dari ID perangkat (di versi web: ID acak yang dibuat browser) dan email (tidak bisa dikembalikan menjadi data asli) untuk mencegah trial ganda.
  • Analytics produk: nama event (misalnya "CV diekspor") beserta kode sederhana (format, template, jumlah). Tidak berisi isi CV, nama, kontak, atau teks bebas.

2. Tujuan dan dasar pemrosesan

  • Menyediakan layanan yang kamu minta (menyusun, menyimpan, menyinkronkan, dan mengekspor CV) — pelaksanaan perjanjian.
  • Bantuan AI (merapikan teks, ringkasan, analisis, menerapkan rekomendasi, memindahkan isi CV lama yang kamu impor) — persetujuan yang kamu berikan di aplikasi sebelum fitur AI dipakai.
  • Mencegah penyalahgunaan trial dan menjaga biaya layanan — kepentingan sah.
  • Meningkatkan produk lewat analytics tanpa data pribadi — kepentingan sah.

3. Pemrosesan oleh AI

  • Super AI adalah nama fitur AI di Potensiku. Saat kamu memakainya, data yang diperlukan dikirim ke penyedia AI (saat ini Anthropic, model Claude) melalui server kami.
  • Untuk CV dari CV Builder, nama, email, nomor telepon, kota, foto, dan tautan tidak dikirim ke AI.
  • Untuk file PDF/DOCX yang kamu unggah, isi file dikirim apa adanya (termasuk data diri di dalamnya) agar bisa dibaca.
  • Penyedia AI tidak memakai data dari API untuk melatih model, dan file tidak disimpan di server Potensiku.
  • AI hanya memakai fakta dari datamu; setiap perubahan AI harus kamu setujui.

4. Penyimpanan dan keamanan

  • Data akun dan CV disimpan di Supabase (server di Singapura) dengan Row Level Security: hanya pemilik akun yang bisa membaca datanya.
  • Hasil analisis, foto profil, dan file PDF/DOCX yang kamu simpan berada di perangkatmu: di HP untuk aplikasi Android, atau di penyimpanan browser (localStorage) untuk versi web. Data ini ikut terhapus bila kamu menghapus data situs di browser.
  • Komunikasi terenkripsi (HTTPS). Kunci API AI hanya ada di server.

5. Transfer ke luar negeri

Data diproses di Singapura (Supabase) dan Amerika Serikat (penyedia AI). Masuk dengan Google diproses oleh Google sesuai kebijakan privasinya. Kami memilih penyedia dengan perlindungan data yang setara atau lebih tinggi sesuai Pasal 56 UU PDP.

6. Retensi

  • Data akun dan CV disimpan selama akunmu aktif.
  • Saat kamu menghapus data dari akun (menu Profil > Privasi), salinan di server dihapus. Log token (tanpa isi CV) disimpan untuk akuntansi biaya.

7. Hak-hakmu

Kamu berhak mengakses, memperbaiki, menghapus data, menarik persetujuan AI, dan mengajukan keberatan. Sebagian besar bisa langsung dilakukan di aplikasi (ubah profil, hapus data dari akun, keluar). Untuk permintaan lain hubungi halo@potensiku.work. Kami menanggapi paling lambat 3x24 jam (Pasal 32 UU PDP).

8. Anak di bawah umur

Layanan ditujukan untuk pengguna berusia 17 tahun ke atas.

9. Perubahan kebijakan

Perubahan penting akan diberitahukan di aplikasi sebelum berlaku.
